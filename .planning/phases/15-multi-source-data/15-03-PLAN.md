## Task 3.5: 历史数据迁移（Fix M4）

**文件:** `backend/alembic/versions/023_rename_boss_default_source.py`

```python
"""Fix M4 (Phase 15 review): 更新历史 'BOSS直聘 (默认)' source_name。
不要直接改 jd_raw.source_site (会破坏历史审计)，
而是新增 data_sources.name 映射，并在 data_source_metrics 记录 alias。
"""
def upgrade():
    # 1. 重命名新 DataSource
    op.execute("""
        UPDATE data_sources 
        SET name = 'remote_default (v2ex+remotive fallback)'
        WHERE name = 'BOSS直聘 (默认)'
    """)
    # 2. jd_raw.source_site 历史记录保留（不改），但在 pipeline_runs.log 加 alias 提示
    op.execute("""
        UPDATE pipeline_runs
        SET error_log = COALESCE(error_log, '') || E'\\n[Phase 15] 注：原 "BOSS直聘 (默认)" 已重命名为 remote_default。'
        WHERE error_log LIKE '%BOSS直聘%'
    """)
    # 3. 通知 admin (写入 audit log 表)
    op.execute("""
        INSERT INTO audit_log (event, actor, action, detail, created_at)
        VALUES ('DATA_SOURCE_RENAMED', 'migration', 'rename_boss_default',
                'BOSS直聘 (默认) → remote_default (v2ex+remotive fallback)',
                NOW())
    """)
```
