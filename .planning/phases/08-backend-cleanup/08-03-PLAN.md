## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client -> API | /health/detail endpoint exposes internal service status and config booleans |
| API -> DB | health check queries review_queue and pipeline_runs tables |
| API -> external services | ping Neo4j/PostgreSQL/Redis/Ollama |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-05 | Information Disclosure | /health/detail llm_keys | mitigate | Only boolean (true/false) returned, never key values; per D-05 "不泄露值" |
| T-08-06 | Information Disclosure | /health/detail services | accept | Service ping returns ok/error only, no connection strings or credentials |
| T-08-07 | Information Disclosure | /health/detail demo_data | accept | Low-value data (queue counts); helps operators verify demo cleanup; SEC-03 auth is future scope |
| T-08-08 | Denial of Service | /health/detail Ollama ping | mitigate | httpx timeout=3.0s prevents hanging; try/except returns error status not exception |
| T-08-SC | Tampering | httpx import | accept | httpx already a project dependency (llm_client.py); no new package install |
</threat_model>
