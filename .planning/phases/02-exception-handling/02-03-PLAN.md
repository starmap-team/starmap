| Boundary | Description |
|----------|-------------|
| Celery worker | Task execution boundary; exceptions must not crash the worker |
| SSE pipeline | Real-time event stream; exceptions must not break the stream for other subscribers |
| Core extraction | LLM call boundary; LLM errors must be wrapped in domain exceptions |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-07 | Denial of Service | Celery worker | high | mitigate | Structured exception handling prevents worker crashes from unhandled errors |
| T-02-08 | Information Disclosure | SSE broadcaster | medium | mitigate | Single subscriber failure doesn't affect other subscribers |
| T-02-09 | Tampering | extraction pipeline | medium | mitigate | LLM errors wrapped in ExtractionLLMError, not leaked to caller |
</threat_model>
