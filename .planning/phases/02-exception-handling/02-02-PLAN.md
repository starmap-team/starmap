    **learning.py (3 occurrences):**
    - Lines 156, 514, 567: `except Exception as exc` → split into:
      - `LearningPathError` for path computation failures
      - `StarMapError` for domain errors
      - `Exception` as last resort

    **Common pattern for all API routes:**
    ```python
    except StarMapError:
        raise  # Let global exception handler convert to structured response
    except (SpecificDomainError, AnotherError) as exc:
        logger.exception("Operation failed: {}", exc)
        raise HTTPException(status_code=4xx, detail=str(exc)) from exc
    except Exception as exc:
        logger.exception("Unexpected error in {operation}: {}", exc)
        raise HTTPException(status_code=500, detail="内部处理异常") from exc
    ```
