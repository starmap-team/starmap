## Tasks

### Task 1: evolution store 新增 fetchEmergingAlerts action
- **Type:** code
- **Files:** `frontend/src/stores/evolution.ts`
- **Details:**
  1. 新增状态和类型：
     ```typescript
     interface EmergingAlert {
       skill_name: string
       category: string
       level: string  // emerging | rising | declining
       z_score: number
       current_frequency: number
       mean_frequency: number
       domains: string[]
       positions: string[]
       alert_message: string
     }
     
     const emergingAlerts = ref<EmergingAlert[]>([])
     const alertsLoading = ref(false)
     ```
  2. 新增 action：
     ```typescript
     async function fetchEmergingAlerts(level?: string) {
       alertsLoading.value = true
       try {
         const params = level ? { level } : {}
         const data = await request.get('/evolution/emerging-alerts', { params }) as { alerts: EmergingAlert[]; total: number; summary: string }
         emergingAlerts.value = data.alerts ?? []
       } catch (e: unknown) {
         if (import.meta.env.DEV) console.error('[Evolution] Failed to fetch alerts:', e)
         emergingAlerts.value = []
       } finally {
         alertsLoading.value = false
       }
     }
     ```
  3. 在 return 中导出 `emergingAlerts`, `alertsLoading`, `fetchEmergingAlerts`
- **Test:** 调用 `fetchEmergingAlerts()` 后 `emergingAlerts` 有数据

### Task 3: Celery beat 定时触发演化分析
- **Type:** code
- **Files:** `backend/app/tasks/celery_app.py`
- **Details:**
  1. 新增演化分析 Celery task（如不存在）：
     ```python
     @celery_app.task(name="app.tasks.celery_app.run_evolution_analysis")
     def run_evolution_analysis():
         """定时触发演化分析 pipeline。"""
         import asyncio
         from app.core.evolution.emergence_finder import EmergenceFinder
         from app.core.evolution.timeseries_loader import load_skill_timeseries_data
         from app.services.resources import resources
     
         async def _run():
             async with resources.pg_sessionmaker() as session:
                 skill_data = await load_skill_timeseries_data(session, include_category=True)
                 if skill_data:
                     finder = EmergenceFinder()
                     report = finder.scan(skill_data)
                     logger.info("Evolution analysis complete: {} emerging, {} rising, {} declining",
                                 len(report.emerging), len(report.rising), len(report.declining))
     
         asyncio.run(_run())
     ```
  2. 新增 beat schedule：
     ```python
     from celery.schedules import crontab
     
     celery_app.conf.beat_schedule = {
         **getattr(celery_app.conf, 'beat_schedule', {}),

             "task": "app.tasks.celery_app.run_evolution_analysis",
             "schedule": crontab(hour="*/6", minute=0),  # 每6小时
         },
     }
     ```
  3. 在 `docker-compose.dev.yml` 中确认 celery-beat 服务存在（或添加）
- **Test:** `celery -A app.tasks.celery_app inspect scheduled` 显示 evolution-analyze 任务
