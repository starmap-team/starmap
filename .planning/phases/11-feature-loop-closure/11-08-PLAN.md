### Task 1: admin_audit_service approve/reject 新增 Neo4j 同步
- **Type:** code
- **Files:** `backend/app/services/admin_audit_service.py`, `backend/app/api/v1/admin.py`
- **Details:**
  1. `admin_audit_service.py` 的 approve/reject 方法新增 `neo4j_driver` 参数
  2. approve 时更新 Neo4j：
     ```python
     async def _sync_neo4j_on_approve(neo4j_driver, item_type: str, item_name: str):
         """Sync approval status to Neo4j (non-blocking)."""
         if not neo4j_driver:
             return
         label_map = {"position": "Position", "skill": "Skill"}
         label = label_map.get(item_type)
         if not label:
             return
         try:
             async with neo4j_driver.session() as session:
                 await session.run(
                     f"MATCH (n:`{label}`) WHERE n.name = $name SET n.trust_score = 1.0, n.status = 'approved'",
                     name=item_name,
                 )
         except Exception as e:
             logger.warning("Neo4j sync failed (non-blocking): {}", e)
     ```
  3. reject 同理，设置 `n.status = 'rejected'`
  4. `admin.py` 中调用 audit service 方法时传入 `neo4j_driver=Depends(get_neo4j_driver)`
- **Test:** admin approve 一个 skill 后，Neo4j 中该节点 trust_score=1.0, status='approved'
