**Phase:** 11-feature-loop-closure

**Depends on:** none

## Goal

1. 学习计划中 skill mastered 后更新 userStore.parsedSkills
2. Evolution changelog 端点参数改为同时支持 skill 和 position 查询

## Tasks

### Task 1: user store 新增 addParsedSkill action
- **Type:** code
- **Files:** `frontend/src/stores/user.ts`
- **Details:**
  1. 新增 `addParsedSkill(skill: string)` action：
     ```typescript
     function addParsedSkill(skill: string) {
       if (!parsedSkills.value.includes(skill)) {
         parsedSkills.value = [...parsedSkills.value, skill]
       }
     }
     ```
  2. 在 return 中导出 `addParsedSkill`
- **Test:** 调用 `addParsedSkill('Docker')` 后 `parsedSkills` 包含 'Docker'

### Task 2: useLearningActions mastered 时更新 parsedSkills
- **Type:** code
- **Files:** `frontend/src/composables/useLearningActions.ts`
- **Details:**
  1. 导入 userStore：
     ```typescript
     import { useUserStore } from '@/stores/user'
     ```
  2. 在 `handleUpdateStatus()` 中，当 status 变为 `mastered` 时更新 parsedSkills：
     ```typescript
     async function handleUpdateStatus(planId: string, skillName: string, status: string) {
       // ...existing updateProgress call...
       
       // When a skill is mastered, add it to user's parsed skills
       if (status === 'mastered') {
         const userStore = useUserStore()
         userStore.addParsedSkill(skillName)
       }
     }
     ```
  3. 可选：显示"重新匹配"提示：
     ```typescript
     if (status === 'mastered') {
       ElMessage.success({ message: '技能已掌握！可前往匹配诊断查看提升效果', duration: 5000 })
     }
     ```
- **Test:** 将 skill 标记为 mastered 后，`userStore.parsedSkills` 包含该 skill

### Task 3: Evolution changelog 参数改为通用 identifier
- **Type:** code
- **Files:** `backend/app/api/v1/evolution.py`, `frontend/src/composables/useEvolutionActions.ts`
- **Details:**
  1. 后端修改 changelog 端点参数：
     ```python
     @router.get("/changelog/{identifier}")
     async def get_changelog(
         identifier: str,
         session: AsyncSession = Depends(get_db_session),
     ):
         """获取技能或岗位的变更日志。identifier 可以是技能名或岗位名。"""
         # 同时查询 Position 和 Skill 相关的 changelog
         # 先尝试按 position 查询，若无结果再按 skill 查询
         position_result = await _query_changelog_by_position(session, identifier)
         if position_result:
             return position_result
         return await _query_changelog_by_skill(session, identifier)
     ```
  2. 前端 `useEvolutionActions.ts` 的 `fetchChangelog` 参数名从 `skillName` 改为 `identifier`（功能不变，语义更准确）：
     ```typescript
     async function fetchChangelog(identifier: string): Promise<void> {
       selectedSkillForDetail.value = identifier
       drawerVisible.value = true
       try {
         await store.fetchChangelog(identifier)
       } catch (e) {
         if (import.meta.env.DEV) console.error('[Evolution] Failed to fetch changelog:', e)
       }
     }
     ```
  3. `evolution.ts` store 中 `fetchChangelog` 的 URL 不变（`/evolution/changelog/${encodeURIComponent(identifier)}`）
- **Test:** EvolutionDashboard 点击 skill 名时，changelog drawer 显示结果（无论按 skill 还是 position 查询）
