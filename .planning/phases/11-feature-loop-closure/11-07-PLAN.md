# 11-07: Dashboard/Pipeline SSE 实时连接接通

**Phase:** 11-feature-loop-closure
**Wave:** 3
**Depends on:** 11-04 (需要 SSE 鉴权修复完成)
**Requirements:** LOOP-11
**Decision refs:** D-18, D-19

## Goal

接通 Dashboard 和 Pipeline 页面的 SSE 实时连接，使实时事件推送可用。

## Tasks

### Task 1: DataDashboard.vue 接入 SSE
- **Type:** code
- **Files:** `frontend/src/pages/DataDashboard.vue`
- **Details:**
  1. 导入 useSSE composable：
     ```typescript
     import { useSSE } from '@/composables/useSSE'
     ```
  2. 在 `onMounted` 中建立 SSE 连接：
     ```typescript
     const baseUrl = import.meta.env.VITE_API_BASE_URL || '/api/v1'
     
     // SSE 实时连接
     const { connected: sseConnected, disconnect: disconnectSSE } = useSSE(
       `${baseUrl}/dashboard/realtime`,
       {
         onMessage: (event) => {
           // 通用消息处理（可选日志）
         },
         storeHandlers: {
           pipeline_update: (data) => dashboardStore.addRealtimeEvent(data),
           quality_alert: (data) => dashboardStore.addRealtimeEvent(data),
           data_milestone: (data) => dashboardStore.addRealtimeEvent(data),
           extraction_complete: (data) => dashboardStore.addRealtimeEvent(data),
         },
       },
     )
     ```
  3. 在 `onUnmounted` 中断开连接：
     ```typescript
     onUnmounted(() => {
       disconnectSSE()
     })
     ```
- **Test:** 打开数据大屏页面，SSE 连接建立，live events 推送正常

### Task 2: PipelineMonitor.vue 接入 SSE
- **Type:** code
- **Files:** `frontend/src/pages/PipelineMonitor.vue`
- **Details:**
  1. 同样导入 useSSE，在 `onMounted` 中建立 SSE 连接：
     ```typescript
     const { connected: sseConnected, disconnect: disconnectSSE } = useSSE(
       `${baseUrl}/pipeline/events`,
       {
         onMessage: (event) => {
           // 通用消息处理
         },
         storeHandlers: {
           pipeline_update: (data) => pipelineStore.handlePipelineEvent(data),
         },
       },
     )
     ```
  2. 在 `onUnmounted` 中断开连接
- **Test:** 打开 Pipeline 监控页面，SSE 连接建立，pipeline 进度更新推送正常

### Task 3: SSE 连接状态 UI 指示器
- **Type:** code
- **Files:** `frontend/src/pages/DataDashboard.vue`, `frontend/src/pages/PipelineMonitor.vue`
- **Details:**
  1. 在页面顶部添加 SSE 连接状态指示：
     ```html
     <el-tag :type="sseConnected ? 'success' : 'danger'" size="small" effect="dark">
       {{ sseConnected ? '实时连接' : '离线' }}
     </el-tag>
     ```
- **Test:** SSE 连接成功时显示绿色"实时连接"，断开时显示红色"离线"
