# 11-02: 学习计划 createPlan 请求结构修复

**Phase:** 11-feature-loop-closure
**Wave:** 1
**Depends on:** none
**Requirements:** LOOP-03
**Decision refs:** D-07, D-08

## Goal

修复前端 `createPlan()` 发送请求体与后端 `CreatePlanRequest` schema 不匹配的问题，添加类型安全的映射函数。

## Tasks

### Task 1: 新增 buildCreatePlanRequest 映射函数
- **Type:** code
- **Files:** `frontend/src/stores/learning.ts`
- **Details:**
  1. 在 `learning.ts` 中新增 `CreatePlanRequest` 接口和映射函数：
     ```typescript
     /** 后端 CreatePlanRequest 对应的前端类型 */
     interface CreatePlanRequestBody {
       position: string
       match_score: number
       skills: Array<{
         skill: string
         importance: string
         gap_level: string
         learning_path: string[]
         target_proficiency?: string
       }>
       available_hours_per_week?: number
     }
     
     /** 从匹配结果构造 CreatePlanRequest 请求体 */
     export function buildCreatePlanRequest(matchResult: Record<string, unknown>): CreatePlanRequestBody {
       const position = (matchResult.position_name ?? matchResult.position ?? '') as string
       const matchScore = (matchResult.match_score ?? 0) as number
       const gapDetail = (matchResult.skill_gap_detail ?? []) as Array<Record<string, unknown>>
       const skills = gapDetail.map((gap) => ({
         skill: (gap.skill ?? gap.skill_name ?? '') as string,
         importance: (gap.importance ?? 'required') as string,
         gap_level: (gap.gap_level ?? '完全缺失') as string,
         learning_path: (Array.isArray(gap.learning_path) ? gap.learning_path : []) as string[],
         target_proficiency: (gap.target_proficiency ?? '熟悉') as string,
       }))
       return {
         position: position || '未知岗位',
         match_score: matchScore,
         skills: skills.length > 0 ? skills : [{ skill: '通用技能', importance: 'required', gap_level: '完全缺失', learning_path: [] }],
         available_hours_per_week: 10.0,
       }
     }
     ```
- **Test:** 构造一个 mock matchResult 对象，验证 `buildCreatePlanRequest()` 输出包含 `position`, `match_score`, `skills` 全部必需字段

### Task 2: 修改 createPlan 使用映射函数
- **Type:** code
- **Files:** `frontend/src/stores/learning.ts`
- **Details:**
  1. 修改 `createPlan(matchResult: Record<string, unknown>)` 方法：
     ```typescript
     async function createPlan(matchResult: Record<string, unknown>) {
       loading.value = true
       error.value = null
       try {
         const payload = buildCreatePlanRequest(matchResult)
         const data = await request.post('/learning/plan', payload) as PlanResponseRaw
         currentPlan.value = mapPlanResponse(data)
         return currentPlan.value
       } catch (e: unknown) {
         error.value = e instanceof Error ? e.message : '创建学习计划失败'
         return null
       } finally {
         loading.value = false
       }
     }
     ```
- **Test:** 调用 `createPlan()` 后确认请求体包含 `match_score` 和完整 `skills` 数组
