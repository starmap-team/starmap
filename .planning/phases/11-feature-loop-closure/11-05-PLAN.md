## Tasks

     ```typescript
     const emit = defineEmits<{
       goBack: []

     }>()
     ```
  2. 在模板底部添加按钮（在 goBack/resetAll 按钮旁）：

     ```html
       创建学习计划
     </el-button>
     ```
- **Test:** Step 4 页面底部显示"创建学习计划"按钮

### Task 2: MatchDiagnosis.vue 处理 createPlan 事件
- **Type:** code
- **Files:** `frontend/src/pages/MatchDiagnosis.vue`
- **Details:**
  1. 导入 learning store 和 router：
     ```typescript
     import { useLearningStore } from '@/stores/learning'
     const learningStore = useLearningStore()
     const router = useRouter()
     ```
  2. 新增 `handleCreatePlan()` 方法：
     ```typescript
     async function handleCreatePlan() {
       if (!matchStore.result) {
         ElMessage.warning('暂无匹配结果，无法创建学习计划')
         return
       }
       try {
         const plan = await learningStore.createPlan(matchStore.result as unknown as Record<string, unknown>)
         if (plan) {
           ElMessage.success('学习计划已创建')
           router.push('/learning')
         }
       } catch (e: unknown) {
         ElMessage.error('创建学习计划失败: ' + (e instanceof Error ? e.message : '未知错误'))
       }
     }
     ```
  3. 在 Step 4 的 `<LearningPathPlan>` 上监听事件：
     ```html
     <LearningPathPlan :gap-skills="gapSkills" @go-back="..." @reset-all="..." @create-plan="handleCreatePlan" />
     ```
- **Test:** 点击"创建学习计划"后，`POST /learning/plan` 发送正确请求体，成功跳转到 `/learning`
