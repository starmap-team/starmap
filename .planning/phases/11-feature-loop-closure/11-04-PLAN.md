## Goal

## Tasks

### Task 1: useSSE.ts EventSource 添加 token query parameter
- **Type:** code
- **Files:** `frontend/src/composables/useSSE.ts`
- **Details:**
  1. 修改 `connectSSE()` 函数，在创建 EventSource 前追加 token：
     ```typescript
     function connectSSE() {
       if (disposed) return
       if (eventSource) {
         eventSource.close()
         eventSource = null
       }
       try {
         // Append JWT token as query parameter for SSE auth
         const token = localStorage.getItem('starmap_token') || localStorage.getItem('token')
         const separator = url.includes('?') ? '&' : '?'
         const authedUrl = token ? `${url}${separator}token=${encodeURIComponent(token)}` : url
         eventSource = new EventSource(authedUrl)
         // ... rest of onopen/onmessage/onerror handlers unchanged
     ```
- **Test:** SSE 连接 URL 包含 `?token=xxx`

### Task 2: useSSE.ts pollOnce 添加 Authorization header
- **Type:** code
- **Files:** `frontend/src/composables/useSSE.ts`
- **Details:**
  1. 修改 `pollOnce()` 函数，在 fetch 调用中添加 Authorization header：
     ```typescript
     async function pollOnce() {
       if (disposed) return
       try {
         const token = localStorage.getItem('starmap_token') || localStorage.getItem('token')
         const headers: Record<string, string> = {
           'Accept': 'application/json',
         }

         }

     ```

### Task 4: 后端 SSE 端点支持 query-param token 验证
- **Type:** code
- **Files:** `backend/app/api/v1/dashboard.py`, `backend/app/api/v1/pipeline/routes.py`
- **Details:**
  1. 在 SSE 端点的依赖注入中新增 query-param token 支持：
     ```python
     from fastapi import Query
     
     async def get_current_user_sse(
         request: Request,
         token: str | None = Query(None, description="JWT token (EventSource fallback)"),
         credentials: HTTPAuthorizationCredentials | None = Depends(_bearer_scheme),
     ) -> dict[str, Any]:
         """SSE-friendly auth: accept token via query param OR Authorization header."""
         if credentials:
             return await get_current_user(credentials)
         if token:
             try:
                 payload = _decode_token(token)
                 return payload
             except ValueError as e:
                 raise HTTPException(status_code=401, detail=str(e)) from e
         # Fall back to standard get_current_user (handles dev mode)
         return await get_current_user(credentials)
     ```
  2. SSE 端点使用 `get_current_user_sse` 替代 `get_current_user`
- **Test:** `GET /dashboard/realtime?token=xxx` 通过鉴权
