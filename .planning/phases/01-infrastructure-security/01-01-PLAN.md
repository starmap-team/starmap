<task type="auto">
  <name>Task 2: Generate new self-signed development certificates to replace exposed credentials</name>
  <files>secrets/neo4j/neo4j.cert.pem, secrets/neo4j/neo4j.key.pem, secrets/postgres/server.crt, secrets/postgres/server.key, secrets/ssl/cert.pem, secrets/ssl/key.pem</files>
  <action>
    Per D-01 (INFRA-01): Generate new self-signed certificates to replace the old ones that were tracked in git. Since `secrets/` is now in `.gitignore`, the new certificates will NOT be tracked.

    The certificates are used by Docker Compose services (Neo4j TLS, PostgreSQL SSL, Nginx SSL). The enable-ssl.sh script at `secrets/postgres/enable-ssl.sh` handles the PostgreSQL SSL setup at container startup and expects `server.crt` + `server.key` in `/etc/postgresql/certs/`.

    Generate three sets of certificates:

    1. **Neo4j**: Generate a self-signed cert+key pair for Neo4j Bolt TLS:
       - `secrets/neo4j/neo4j.cert.pem` — certificate
       - `secrets/neo4j/neo4j.key.pem` — private key (chmod 600)

    2. **PostgreSQL**: Generate a self-signed cert+key pair for PostgreSQL SSL:
       - `secrets/postgres/server.crt` — certificate
       - `secrets/postgres/server.key` — private key (chmod 600)

    3. **Generic SSL** (Nginx frontend TLS):
       - `secrets/ssl/cert.pem` — certificate (also used to create cert.pfx)
       - `secrets/ssl/key.pem` — private key (chmod 600)
       - `secrets/ssl/cert.pfx` — PKCS12 bundle (for Windows, created from cert.pem + key.pem)

    Use OpenSSL (available in Git Bash on Windows) with the following parameters:
    - RSA 2048-bit key
    - Validity: 3650 days (10 years, dev only)
    - Subject: `/CN=starmap-dev.local`
    - No passphrase on private keys (Docker Compose mounts them without password)

    For the PFX bundle: `openssl pkcs12 -export -out secrets/ssl/cert.pfx -inkey secrets/ssl/key.pem -in secrets/ssl/cert.pem -passout pass:`

    Each command must use `-nodes` (no DES) to create unencrypted private keys.

    After generation, verify the certificates with `openssl x509 -in <file> -text -noout | head -5` to confirm they are valid PEM certificates.
  </action>
  <verify>
    <automated>
      openssl x509 -in secrets/neo4j/neo4j.cert.pem -text -noout 2>&1 | head -3 && openssl x509 -in secrets/postgres/server.crt -text -noout 2>&1 | head -3 && openssl x509 -in secrets/ssl/cert.pem -text -noout 2>&1 | head -3 && echo "PASS: All certs are valid PEM"
    </automated>
  </verify>

  </done>
