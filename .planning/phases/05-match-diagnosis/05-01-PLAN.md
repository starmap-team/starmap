|----------|-------------|
| Client (browser) → API | 简历技能自述 / 匹配请求 / 批量请求 / 推荐扫描跨此边界 |

| API → 匹配引擎缓存 | 全局单例 MatchCache（进程内共享）跨请求复用 |
