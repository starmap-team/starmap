## Test Infrastructure

### 统一 Mock 策略
- **Store mock**: 使用 `setActivePinia(createPinia())` + 手动设置 store 状态（`store.loading = true`），无需 `@pinia/testing`
- **API mock**: 使用 `vi.mock()` mock `@/api/client.ts` 中的 API 调用
- **Router mock**: 使用 `vi.mock('vue-router')`，提供 `useRoute` / `useRouter` 的简单实现
- **Element Plus**: 全局注册，或使用 `global.plugins` / `global.stubs` 在 mount 时注入

### 通用测试模板
```typescript
import { describe, it, expect, vi, beforeEach } from 'vitest'
import { mount } from '@vue/test-utils'
import { setActivePinia, createPinia } from 'pinia'
import { renderPage } from './helpers'

describe('PageName', () => {
  beforeEach(() => {
    setActivePinia(createPinia())
    vi.clearAllMocks()
  })

  it('renders correctly', () => {
    const wrapper = renderPage(PageComponent)
    expect(wrapper.text()).toContain('预期文本')
  })

  it('shows loading state', () => {
    // mock store with loading=true
    const store = useSomeStore()
    store.loading = true
    const wrapper = renderPage(PageComponent)
    expect(wrapper.find('.el-loading').exists()).toBe(true)
  })

  it('shows empty state', () => {
    // mock store with empty data
    const store = useSomeStore()
    store.items = []
    const wrapper = renderPage(PageComponent)
    expect(wrapper.text()).toContain('暂无数据')
  })

  it('shows error state', () => {
    // mock store with error
    const store = useSomeStore()
    store.error = '加载失败'
    const wrapper = renderPage(PageComponent)
    expect(wrapper.text()).toContain('错误')
  })
})
```
