### Task 1 — Tracer: Boss 直聘 End-to-End（含适配器 spike + 抽取翻译）— verify-first

**目标:** 跑通“中文站爬取 → 抽取 → 翻译（如英文站点）→ 投影图谱 → 前端可见来源与时间”全链路 tracer；首源 Boss；不限 Apify（无 token 时降级为本地请求并诚实标注）。

**步骤（每步 validate-first）:**

1. **1.1 适配器 spike（≤20min）** — 探测 BOSS 直聘 (`https://www.zhipin.com/`) 与拉勾 (`https://www.lagou.com/`) 与猎聘 (`https://www.liepin.com/`) 可达性 + 反爬强度：
   - `curl -I -A "Mozilla/5.0 ..."` 各 URL，记录 HTTP 状态、`Set-Cookie`、`Server`、`Content-Type`、是否 200/403/JS-challenge。
   - 判断：是否被 Akamai/JS challenge 拦截？是否需 Apify/Residential proxy？
   - 产出 `crawler/docs/board-recon.md`（可行性 + 选型：某源可直连 / 需 Apify / 不可行）
   - **Checkpoint:decision** — 若≥1 源 200 直连 OK，进 1.2；若全部需 Apify 且无 token，进 1.2b（stub 路径 + 页面标注“待接入 Apify”）；若不可行，进 1.2c（降级到 remotive/英文源 跑通 tracer，标注中文源待解）
2. **1.2 适配器实现** — `crawler/scripts/fetch_chinese_board.py`（中文站统一接口：select_board(name)→board_url、fetch_jd_list(board, page)→List[JD raw dict]，含 WAF 降级：随机 UA + 限速 + 失败重试）。**含三种源适配器注册**：BOSS=zhilian-style、拉勾=lagou、猎聘=liepin（实现可各为 1 个 stub 返回 mock 但接口齐；spike 之后填充真实）。同步实现 `crawler/scripts/apify_boss.py`（若走 Apify 路径）。
3. **1.3 翻译模块** — `backend/app/core/extraction/translation.py`：
   - 函数 `translate_title_industry(title: str, industry: str, target_lang='zh-CN') -> dict[zh_title, zh_industry]`：检测输入是否含 CJK，若已含 CJK 直接返回原值；否则调用 LLM（复用 `llm_client.py` 现有 provider 链：MiMo→DeepSeek→Qwen→Ollama 降级）一次性翻译。
   - prompt 模板：明确简短、不幻觉、补全行业术语；input 含源语言检测信息。
   - 加 `name_cn`/`industry_zh` 字段到抽取结果（保留原 `name`/`industry`）。
4. **1.4 抽取 hook** — `backend/app/core/extraction/jd_extract.py`：在抽取位置/技能后、归一化前调用 `translation.translate_title_industry`；仅对源语言非 CJK 触发；写 `name_cn`。
5. **1.5 orchestrator 路由** — `backend/app/core/pipeline/orchestrator.py` 数据源→适配器调度：crawl stage 根据 `data_sources.source_type` 选择 `fetch_chinese_board` (job_board) 或 `apify_*`；`extract` stage 自动经翻译模块。
6. **1.6 Tracer 跑通（verify-first）** — 手动触发 1 次 BOSS 采集（直接 python 调 `run_incremental.py` 或新写 `crawler_run_once.py`），确认：
   - `jd_raw` 出现 source_site=BOSS 的行（≥1）
   - `data_sources`（boardName=BOSS Zhipin）`total_records>0` 且 `last_crawl_at` 更新
   - `position_records.name_cn` 非空（对 BOSS 中文源天然中文 → 来自 JD 标题；如 BOSS 源不可行降级到 remotive，则翻译成中文）
   - Neo4j `Position` 节点创建（GRAPH_SYNC 阶段）
   - 浏览器 `/position/<id>` 列表/详情可见
   - 浏览器 DataSources 页显示 `source: BOSS` + `last_crawl_at` 时间
   - 截图 `tests/e2e/investigations/phase15/boss-tracer.png` — 含 KPI 卡片 + 卡片 source 标记 + 详情
   - **Acceptance:** API + PG + Neo4j + 截图 四层一致

**Risk:** BOSS 反爬失败 → 1.2c 降级到 remotive 英文源跑通 tracer（I18N-01 翻译路径仍验证）；不阻塞后续任务。
