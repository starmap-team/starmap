# 10-01: Playwright 官方镜像 + Celery Worker 容器化

**Goal:** (D-01) 用 `mcr.microsoft.com/playwright/python:v1.49.0-jammy` 作为 celery-worker 容器 base image，替代当前 `python:3.11-slim` 自装 Chromium 的不可复现路径。

## Tasks

<task id="T1" title="新建 celery worker Dockerfile（基于 Playwright 官方镜像）">
<read_first>
- backend/Dockerfile.dev（当前 main API base 镜像 — 不可重用给 celery，因为 main 不需要 Chromium）
- docker-compose.dev.yml（找出当前 celery-worker 服务块定义，看现 base 引用哪个 Dockerfile）
- .env.example（确认 PIPELINE_BOOTSTRAP、PROXY_LIST 字段是否已存在或需补）
</read_first>
<action>
1. 新建文件 `backend/Dockerfile.celery`，内容基线：
   ```
   # StarMap celery-worker 镜像（Playwright + 反检测浏览器）
   # PIPE-01: 使用 Playwright 官方镜像免去 Chromium 重复安装
   FROM mcr.microsoft.com/playwright/python:v1.49.0-jammy

   # 系统依赖（与 backend/Dockerfile.dev 对齐 — psycopg build / 编译工具）
   RUN apt-get update && apt-get install -y --no-install-recommends \
       build-essential libpq-dev curl \
       && rm -rf /var/lib/apt/lists/*

   WORKDIR /app

   ENV POETRY_VIRTUALENVS_CREATE=false \
       POETRY_NO_INTERACTION=1 \
       POETRY_CACHE_DIR=/tmp/poetry_cache \
       PYTHONUNBUFFERED=1

   RUN pip install --no-cache-dir poetry==2.4.1

   COPY pyproject.toml poetry.lock* ./
   RUN poetry install --no-root && rm -rf $POETRY_CACHE_DIR

   # 拷贝 crawler 包（Playwright-stealth BOSS 爬虫依赖）
   COPY crawler/ ./crawler/

   # 默认启动 celery worker（具体 queues / beat 由 docker-compose 决定）
   CMD ["celery", "-A", "app.tasks.celery_app.celery_app", "worker", "--loglevel=info"]
   ```
2. 不修改 `backend/Dockerfile.dev`（那是 main API 的镜像，与 PIPE-01 无关）
</action>
<acceptance_criteria>
- `cat backend/Dockerfile.celery` 第一行包含 `FROM mcr.microsoft.com/playwright/python:v1.49.0-jammy`
- 文件以 `.dev` 镜像相同模式安装 poetry + 依赖（POETRY_VIRTUALENVS_CREATE=false 等）
- 文件末尾 `CMD` 是 `celery -A app.tasks.celery_app.celery_app worker --loglevel=info`
- `grep -q "playwright/python:v1.49.0-jammy" backend/Dockerfile.celery` 退出码 0
</acceptance_criteria>
</task>
