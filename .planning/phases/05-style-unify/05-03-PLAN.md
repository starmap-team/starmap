Create `tests/e2e/test_2d_3d_color_consistency.py` with the following structure (do NOT fence code blocks inside the action — the executor writes the actual implementation):

1. Module docstring stating purpose (D-08: 2D/3D KA color diff verification, +/- 5 RGB tolerance per D-11).

2. Imports: `argparse`, `sys`, `time`, `pathlib.Path`. Import `playwright.sync_api.sync_playwright` lazily inside `run_live_check()` so `--self-test` does not require Playwright installed.

3. Copy verbatim from `tests/e2e/smoke_test.py`: the `Colors` class (GREEN/RED/YELLOW/RESET/BOLD constants), the `log()` function, the `check()` function. These are 30 lines of proven helpers and re-implementing them is exactly the kind of slop D-09 "复用启动器" prevents.

4. New pure function `rgb_diff(c1: tuple, c2: tuple) -> int` returning `max(abs(a-b) for a,b in zip(c1, c2))`.

5. New pure function `dominant_color_from_bytes(png_bytes: bytes, region: tuple = (10, 10)) -> tuple`:
   - If `PIL.Image` is importable: open with `Image.open(BytesIO(png_bytes))`, crop the center `region` pixels, return the mean RGB tuple.
   - Else: decode the PNG IHDR + IDAT chunks manually with `zlib` (stdlib). If manual decode fails, fall back to scanning the raw bytes for the most-frequent 3-byte triplet that lies in a "looks-like-RGB" range. Document the fallback as best-effort and skip the live run if it fails (return `None` and emit a yellow warning).

6. New `run_self_test()` that constructs two synthetic `bytes` blobs with known RGB triples, calls `dominant_color_from_bytes` on each, asserts `rgb_diff` returns 0 for identical inputs and <= 5 for inputs differing by 5 in one channel. Exits 0 on success, non-zero with the failure message otherwise.

7. New `run_live_check(args)`:
   - Launch Chromium headless via `sync_playwright()`.
   - `page.goto(args.base_url)`, `wait_for_load_state("networkidle")`.
   - Click the 2D button (selector: prefer `button:has-text("2D")`, then `button:has-text("2d")`, then `[data-viewmode="2d"]` — first match wins).
   - Locate node via `page.locator(f'[data-node-id="{args.node_id}"]').first`; if not found, fall back to the first `.ka-node` / `[data-type="KnowledgeArea"]` element.
   - Screenshot the bounding box (clip to element bbox) into `args.output_dir / "2d.png"`.
   - Click the 3D button (same selector pattern with "3D"/"3d"/`[data-viewmode="3d"]`). Wait 1.5s for Three.js render frame.
   - Repeat screenshot into `args.output_dir / "3d.png"`.
   - Compute dominant colors, run `rgb_diff`, compare to `args.tolerance`.
   - Use `check()` from smoke_test.py to log pass/fail. On fail, print the diagnostic triple from the spec.

8. `def main()` with argparse: `--base-url` (str, default `http://localhost:5173`), `--node-id` (str, default `ka-001`), `--tolerance` (int, default 5), `--output-dir` (Path, default `./tests/e2e/_artifacts`), `--self-test` (action="store_true"). If `--self-test`, run `run_self_test()` and return. Else `args.output_dir.mkdir(parents=True, exist_ok=True)` then `run_live_check(args)`.

9. `if __name__ == "__main__": sys.exit(main() or 0)`.
