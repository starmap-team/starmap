## Task 1: 添加 --ci 子命令和 CI 模式输出

<read_first>
- scripts/quality_report.py — 当前 main() 实现（line 329-387），evaluate_jd_extraction/evaluate_resume_extraction/evaluate_matching 函数签名
</read_first>

<action>
在 `scripts/quality_report.py` 中：

1. 在 `main()` 的 argparse 中添加 `parser.add_argument("--ci", action="store_true", help="CI 模式：输出 git HEAD + 三方准确率，fail 时 exit 1")`
2. 在 `main()` 生成 report 后，如果 `args.ci` 为 True：
   a. 获取 git HEAD commit hash：`subprocess.run(["git", "rev-parse", "--short", "HEAD"], capture_output=True, text=True).stdout.strip()`
   b. 在 report dict 中添加 `"git_head": git_hash`
   c. 在 markdown 输出前添加一行 `> CI Run: {git_hash}`
   d. 同时输出 JSON 到 `{output_dir}/quality_report_ci.json`（与现有 quality_report.json 格式一致，但加 git_head 字段）
   e. 退出码：遍历 `report["metrics"]`，任一 `m["status"] == "fail"` 则 `sys.exit(1)`，否则 `sys.exit(0)`
3. 在文件顶部添加 `import subprocess`（如果尚未存在）
</action>

<acceptance_criteria>
- `scripts/quality_report.py` 包含 `parser.add_argument("--ci"`
- `scripts/quality_report.py` 包含 `subprocess.run(["git", "rev-parse", "--short", "HEAD"]`
- `scripts/quality_report.py` 包含 `sys.exit(1)` 在任一指标 fail 时
- `scripts/quality_report.py` 包含 `sys.exit(0)` 在全部 pass 时
- `python scripts/quality_report.py --ci --golden data/golden/ --system data/output/ --output reports/` 可执行（无 import 错误）
