# Plan 04-04: GAP-04-01 — 闭环 Step 4 传入 driver + db_session 给 run_match

**Objective:** 修复闭环 Step 4 匹配诊断失败的问题。根因是 `loop_orchestrator._step4_match_diagnosis` 调用 `run_match` 时未传入 `driver` 和 `db_session`，导致 `_load_target_profile` 无法从 DB 或 Neo4j 加载岗位 profile。

## Task 1: 为 _step4_match_diagnosis 添加 driver 和 session 参数传递

- backend/app/services/match_service.py — run_match 签名 (line 36-53)
- backend/app/core/matching/service.py — _load_target_profile (line 72-142)
</read_first>

<action>
在 `backend/app/core/pipeline/loop_orchestrator.py` 中：

1. 修改 `_step4_match_diagnosis` 方法签名，添加可选参数：
   ```python
   async def _step4_match_diagnosis(
       self,
       target_position: str,
       extracted_skills: list[dict[str, Any]],
       graph_available: bool,
       driver: Any = None,
       db_session: Any = None,

   ```

2. 在 `run_match` 调用中传入 driver 和 db_session：

   ```python
   step4 = await self._step4_match_diagnosis(
       target_position,
       step2_data.get("skills", []),
   ```
