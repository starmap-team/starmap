# Plan 17-01: 移除 timeseries 从核心 DAG

## 目标

按设计文档 `docs/architecture/pipeline.md:30` (timeseries 不属于核心 ETL DAG)，把 timeseries 从 `ALL_STAGE_NAMES` 移除，让 UI 不再把它当作必选 stage。

## Task 1: pipelineConfig.ts 改 ALL_STAGE_NAMES [frontend]

**文件:** `frontend/src/stores/pipelineConfig.ts`

```ts
// Phase 17-01: timeseries 移出核心 DAG (设计文档明确)
```
