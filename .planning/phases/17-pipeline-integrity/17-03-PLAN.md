# Plan 17-03: import 校验 + graph_sync 部分成功 (B3, B4)

## 目标

LLM 抽取时可能漏 `position_name`,导致 graph_sync 失败。当前是"一坏全坏",改成"坏数据兜底,好数据照入"。

## Task 1: import 阶段加 position_name 兜底 [backend]

**文件:** `backend/app/core/pipeline/executor.py` (execute_import 函数末尾)

```python
# Phase 17-03 (Fix B3): 防御性兜底 — LLM 偶尔漏 position_name
# 不阻塞 import, 标记 invalid_count, 让 graph_sync 可继续
invalid_position = 0
for extraction in extraction_records:
    name = extraction.get("position_name")
    if not name or not str(name).strip():
        extraction["position_name"] = "(未命名职位)"
        extraction["_invalid_position"] = True  # 标记供 graph_sync 跳过
        invalid_position += 1

if invalid_position > 0:
    logger.warning(
        f"import: {invalid_position}/{len(extraction_records)} extractions missing position_name, 已用兜底"
    )
    audit_log(AuditEntry(
        event=AuditEvent.PII_DETECTED,  # 复用 PII audit event, 反正都是数据问题
        actor=actor,
        action="import_missing_position_name",
        detail=f"run_id={run_id}, invalid={invalid_position}/{len(extraction_records)}"
    ))
```

    """Returns triples merged. Skips invalid records silently."""
    if extraction.get("_invalid_position"):

## Task 3: graph_sync 阶段 try/except 隔离单条 [backend]

**文件:** `backend/app/core/pipeline/executor.py` (execute_graph_sync 循环)

```python
# Phase 17-03 (Fix B4): 单条失败不阻塞整个 batch
merged = 0
skipped = 0
for extraction in extractions:
    try:
        result = write_extraction_to_graph(extraction)
        if result > 0:
            merged += result
        else:
            skipped += 1
    except Exception as e:
        logger.warning(f"graph_sync: skipped extraction {extraction.get('id')}: {e}")
        skipped += 1
        continue  # 不抛出,继续下一条

_run_async(_publish_stage_progress(
    run_id, "graph_sync", "running", progress=0.9,
    current_activity=f"图谱同步中: {merged} 成功 / {skipped} 跳过"
))
```
