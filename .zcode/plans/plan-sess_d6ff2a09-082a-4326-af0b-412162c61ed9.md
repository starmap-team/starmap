## Wave 1: 🔴 CRITICAL Security Fixes (必须先修)

### 1.1 前端 Auth 流修复 (5 files)

**`frontend/src/api/request.ts`**:
- 请求拦截器添加 Authorization header（从 localStorage 读取 token）
- 401 响应处理中清除 localStorage token + 调用 `clearUser()`
- 移除 `console.error`，改用 `if (import.meta.env.DEV)` 守卫
- `baseURL` 改为 `import.meta.env.VITE_API_BASE_URL || '/api/v1'`

**`frontend/src/stores/user.ts`**:
- `clearUser()` 增加 `localStorage.removeItem('starmap_token')` 和 `localStorage.removeItem('token')`
- `decodeToken()` 增加 `exp` 过期检查，过期返回 null
- 新增 `logout()` 方法：clearUser + clearResume

**`frontend/src/router/index.ts`**:
- 移除 `document.cookie.includes('session=')` 不可靠检查
- 所有非 PUBLIC 路由添加 `requiresAuth: true`（除首页外）
- 添加 `/login` 路由定义（指向 Login.vue 或占位组件）
- 401 事件监听中调用 `userStore.logout()`

**`frontend/src/components/Graph3D.vue`** (XSS):
- `nodeLabel` 回调中对 `n.properties.name` 做 HTML 转义
- 添加 `escapeHtml()` 工具函数

**`frontend/src/pages/PipelineAnalysis.vue`**:
- 外部链接添加 `rel="noopener noreferrer"`

### 1.2 后端安全修复 (4 files)

**`backend/app/config.py`**:
- 新增 validator：`app_env == "production"` 时 `app_debug` 必须为 False
- 非 production 环境也 warning 如果 secret_key == `_UNCONFIGURED`（已有，但加 log level 升级）

**`backend/app/main.py`**:
- Rate limiter: 添加 periodic cleanup（每次请求时顺便清理过期 bucket，限制总 bucket 数 ≤ 10000）
- `/health/detail` 添加 `Depends(get_current_user)` 保护
- 移除未使用的 `bindparam` import

**`backend/app/api/v1/pipeline/routes.py`**:
- `/analyze` 和 `/export` 添加文件大小限制 (10MB) 和 MIME 类型校验
- 敏感操作端点添加 `Depends(require_admin)`：trigger, retry, resume, schedule trigger

**`backend/app/services/admin_graph_service.py`**:
- `list_nodes()` 中 `node_type` 不在 `_ALLOWED_LABELS` 时，不拼接 f-string（当前已跳过，但加显式 else 分支日志）
- 在 service 层每个方法入口重新验证 `_ALLOWED_LABELS`（defense in depth）

### 1.3 测试凭证清理 (2 files)

**`backend/tests/unit/test_datasource_api.py`**:
- 移除硬编码 `"Bearer dev-token"` header（依赖 `_override_user` fixture 即可）

**`tests/e2e/pipeline_smoke_test.py`**:
