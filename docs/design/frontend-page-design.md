# StarMap 全站前端页面设计

**日期**: 2026-07-14
**状态**: 设计中
**参考**: Marble (withmarble.com) 视觉语言 + StarMap 现有 design-tokens.css + Element Plus 组件库
**原则**: 深色优先 · 数据即界面 · 沉浸式交互 · 零新 token

---

## 0. Marble 视觉语言提炼

Marble 的在线前端 (`withmarble.com/curriculum`) 是一个 3D 知识图谱可视化，核心设计语言：

| 维度 | Marble 做法 | StarMap 对应 |
|------|-----------|-------------|
| 深色沉浸背景 | 深空色背景突出发光节点 | `--background` 深色模式 + `--dash-surface` 沉浸 token |
| 语义着色 | 节点按学科着色（Science=绿, Math=蓝...） | `graphColors.ts` DOMAIN_COLORS 11 色板 |
| 发光效果 | 节点带辉光 + 连线半透明 | `--dash-accent-*` glow tokens + `withAlpha()` |
| 极简文案 | 一段话 + 交互提示，无冗余 | 品牌标语 + 操作提示，无装饰性文字 |
| 交互即探索 | Drag/Tap/Scroll 无菜单 | Graph3D OrbitControls + node-click → DetailPanel |
| 卡片浮层 | 详情面板半透明毛玻璃 | `--surface-overlay` + `backdrop-filter: blur()` |
| 统计条带 | "0 concepts and 0 prerequisite links" | HomeKpiStrip 四指标条 |

### 2.1 Login.vue — 品牌入口

**Marble 参考**: Marble 官网首页的"hero + CTA"布局——左侧品牌视觉锚点，右侧极简行动入口。

```
┌──────────────────────────────────────────────────────────┐
│                                                          │
│  ┌────────────────────┐  ┌────────────────────────────┐  │
│  │                    │  │  ⭐ StarMap 星图            │  │
│  │  3D 粒子背景       │  │  人才能力星云导航系统      │  │
│  │  (Graph3D          │  │                            │  │
│  │   auto-rotate      │  │  ┌──────────────────────┐  │  │
│  │   opacity=0.25     │  │  │ 👤 用户名            │  │  │
│  │   maxNodes=150)    │  │  └──────────────────────┘  │  │
│  │                    │  │  ┌──────────────────────┐  │  │
│  │                    │  │  │ 🔒 密码        👁   │  │  │
│  │                    │  │  └──────────────────────┘  │  │
│  │                    │  │  ┌──────────────────────┐  │  │
│  │                    │  │  │       登 录          │  │  │
│  │                    │  │  └──────────────────────┘  │  │
│  │                    │  │                            │  │
│  └────────────────────┘  │  深色模式 · v1.0          │  │
│                           └────────────────────────────┘  │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

| 元素 | Token / 规格 | 说明 |
|------|-------------|------|
| 左侧 3D | 复用 `Graph3D.vue` | auto-rotate, opacity=0.25, maxNodes=150 |
| 品牌标题 | `--text-display-xl` / `--weight-extrabold` | 36px, 前景色 |
| 副标题 | `--text-body` / `--weight-medium` / `--muted-foreground` | 14px |
| 登录卡片 | `background: --surface-1` / `--radius-panel` / `--shadow-float` | 毛玻璃浮层 |
| 输入框 | `el-input` size=large / prefix-icon | Element Plus |
| 登录按钮 | `type=primary` / `width=100%` / 渐变 `--chart-1→--chart-2` | 品牌渐变 |
| 深色切换 | 右下角小字链接 | 复用 MainLayout `toggleDarkMode()` |

**关键交互**:
- 登录成功：左侧 3D opacity 0.25→1.0（300ms），右侧卡片 fade-out（200ms），实现"登录即进入图谱"
- 登录失败：保留用户名，仅清空密码
- Enter 提交；Tab 在用户名↔密码↔按钮间切换

**移动端**（≤768px）：单栏，3D 背景全屏，卡片居中叠加

### 3.2 统计数字

### 3.3 状态标签映射

| 语义 | el-tag type | 颜色来源 |
|------|-----------|---------|
| 成功/已掌握/活跃 | success | `--success` |
| 警告/进行中/暂停 | warning | `--warning` |
| 危险/失败/错误 | danger | `--destructive` |
| 信息/待审核 | info | `--info` |

### 3.4 进度条颜色阈值

```typescript
function progressColor(value: number): string {
  if (value >= 80) return cv('--success')
  if (value >= 60) return cv('--warning')
  return cv('--destructive')
}
```

### 3.5 图表主题桥接

所有 ECharts 实例统一通过 `chartTheme.ts` 的 `chartColors()` 获取颜色，
确保与 CSS 变量同步，深色/浅色自动切换。

## 10. 深色/浅色主题策略

| 页面 | 默认主题 | 说明 |
|------|---------|------|
| Login | 深色 | 3D 粒子背景在深色下效果最佳 |
| Home / DataDashboard | 深色 | Graph3D 沉浸式体验 |
| 其他所有页面 | 跟随系统 | `MainLayout.vue` 已有 `toggleDarkMode()` |

深色模式下的关键视觉差异：
- 卡片背景: `--surface-1` 自动变深（`--card` token 在 `html.dark` 下由 App.vue 切换）
- 阴影: `--shadow-float` 在深色下透明度从 0.12→0.35
- 图表: `chartTheme.ts` 的 `chartColors()` 自动读取深色 token
- 3D 场景: `SCENE_PALETTE.background` 固定为 `#0a0e1a`
