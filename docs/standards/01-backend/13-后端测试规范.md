# 后端测试规范

## 分层

- Unit：纯算法、Schema、服务分支和路由行为，快速且确定。
- Integration：真实数据库/适配边界，验证事务、迁移和跨模块契约。
- E2E：仓库 `tests/e2e/` 驱动运行中的服务。

## 规则

- 覆盖率门禁以 `backend/pyproject.toml` 为唯一来源。
- 新行为先有能失败的测试；bug 修复必须有回归用例。
- 测试统一错误格式、401/403、所有权和输入边界。
- 不调用真实 LLM、生产数据库或生产 Neo4j。
- 时间、UUID、随机和网络必须可控制。
- 不维护测试文件/通过用例的手写清单，使用 `rg --files` 和 pytest 收集结果。

## 命令

```bash
cd backend
poetry run pytest
poetry run pytest tests/unit/<target>.py -q
```
