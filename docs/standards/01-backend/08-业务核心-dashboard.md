# Dashboard 核心规范

## 范围

`core/dashboard/` 维护看板聚合和 SSE 广播辅助。API 服务负责从 PG/Neo4j 获取符合语义的数据并映射到契约。

## 规则

- KPI 定义集中维护，前端不从不相关字段反推。
- PG 指标与 Neo4j 图指标明确标注来源和口径。
- SSE 事件有稳定 type、timestamp 和 payload；轮询返回同等语义。
- 无数据返回空集合/零值和明确状态，不注入伪造演示数据。
- 聚合查询有上限、分页或窗口，避免看板请求触发全库扫描。

## 验证

测试聚合口径、空数据、依赖不可用降级、SSE 清理和响应 Schema。
