# 数据库与会话规范

## PostgreSQL

- Async engine/session 由统一工厂和 FastAPI 依赖提供。
- 请求/服务明确事务边界；异常 rollback，成功 commit。
- 查询参数化，分页/上限明确，避免 N+1。
- 生产强制符合配置校验的 SSL mode。

## Alembic

- 新建 revision，不修改已应用文件。
- 多 head 使用 merge revision。
- 当前 head 通过 `poetry run alembic heads` 查询，不在文档硬编码编号。
- migration 评审包含锁表、数据回填、默认值和恢复方案。

## Neo4j

- Driver 生命周期由 resources 管理。
- 业务事实来自 PG，图节点使用 `canonical_id`。
- Cypher 参数化；动态 label/type 必须来自白名单。

## 验证

```bash
cd backend
poetry run alembic heads
poetry run alembic upgrade head
poetry run pytest tests/integration
```
