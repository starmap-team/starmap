# Learning 核心规范

## 范围

`core/learning/` 负责技能差距到学习路径的排序、依赖处理和进度计算；`services/learning_service.py` 负责持久化与用户所有权。

## 规则

- 路径输入来自已验证的匹配差距，不自行重算另一套匹配分数。
- 技能依赖必须可检测循环，并为无法排序的输入返回结构化错误。
- 计划和进度属于用户，读取和更新都校验所有权。
- 进度更新幂等，服务端值是权威状态。
- 推荐与进度 API 使用集中 Schema 和 `snake_case` 字段。

## 验证

覆盖空差距、依赖循环、部分完成、重复更新、越权和计划不存在等行为。
