# 后端入口与配置

## 职责

- `app/main.py`：FastAPI 实例、lifespan、中间件、异常处理、health/ready。
- `app/config.py`：Pydantic Settings 和生产 fail-fast 校验。
- `app/dependencies.py`：认证、数据库、Neo4j 和 Redis 依赖。
- `app/services/resources.py`：应用级 PG/Neo4j/Redis 生命周期。

## 规则

- 所有配置字段在 Settings 定义，并在 `.env.example` 说明。
- 生产必须显式设置 production identity、强密钥、TLS/SSL 和 CORS 域名。
- `DEV_ANON_ADMIN` 默认关闭且生产拒绝开启。
- `/health` 表示存活，`/ready` 表示依赖和迁移就绪；部署门禁用 `/ready`。
- 生产禁用交互式 API 文档。
- 中间件和异常处理返回统一错误结构，不泄露内部异常。

## 验证

cd backend
poetry run pytest tests/unit/test_health.py tests/unit/test_config.py tests/unit/test_dependencies.py
