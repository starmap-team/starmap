# 评估套件规范

## 分层

- Baseline：无外部 LLM、可重复的规则下限。
- Simulated：验证评估框架，不代表模型真实质量。
- Real LLM：记录 provider/model/prompt/dataset/commit/time 的真实运行。
- Domain Golden Set：JD、简历、匹配和 pipeline 分开维护。

## 规则

- Golden truth 与被测流程隔离。
- 数据集变更经评审和版本记录，避免在同一结果中悄悄改真值。
- precision/recall/F1 的规范化和匹配规则固定在评估代码。
- 模拟和真实结果不得混合宣传。
- 报告由运行生成；历史报告移入归档，README 不保存某次指标。
- 核心算法变更提交前运行适用 baseline，外部凭据任务可作为独立门禁。
