# E2E 与集成测试规范

## 位置

- 后端 unit/integration：`backend/tests/`。
- 前端 unit/component：`frontend/src/**/__tests__/`。
- 契约：`tests/contract/`。
- 跨服务与浏览器：`tests/e2e/`。
- 根级补充测试：`tests/unit/`（Python）、`tests/integration/`（前端 API 契约/集成脚本）。
- 一次性报告：`docs/archive/reports/<date>/`。

## 规则

- Unit 快速确定；integration 使用真实边界；E2E 只覆盖关键用户结果。
- Live test 必须显式 base URL，默认禁止生产。
- 浏览器测试验证 UI、网络、控制台错误和可见反馈。
- 测试产物进入 ignored screenshots/traces/results 目录。
- 不把历史报告中的路径、数量或"已通过"作为当前门禁。
- 契约测试比较路径、方法和结构，不只比较 HTTP 200。
- 每个测试可独立运行，不依赖顺序或固定已有数据库记录数。

## 命令

```bash
cd backend && poetry run pytest
cd frontend && npm run test
python tests/e2e/smoke_test.py --base-url http://localhost:8000 --all
```
