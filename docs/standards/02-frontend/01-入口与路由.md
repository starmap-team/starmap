# 前端入口与路由规范

## 边界

`main.ts` 安装 Vue/Pinia/router/Element Plus 等全局依赖；`router/index.ts` 是页面、认证和管理员路由元数据的唯一来源。

## 规则

- 页面使用懒加载；路由 name/path 保持稳定。
- 受保护路由显式 `requiresAuth`，管理员路由同时 `requiresAdmin`。
- 路由守卫调用 `ensureBootstrapped()` 获取服务端用户事实。
- 必改密码流程优先于普通受保护页面。
- 401 由 API 层触发统一 unauthorized 事件，不在各页面重复刷新逻辑。
- 页面标题和 breadcrumb 来自 route meta。

## 验证

覆盖匿名、token 过期、refresh 成功/失败、must-change-password、非管理员和重定向恢复。
