# 样式与设计令牌规范

## 事实源

全局样式和 token 位于 `frontend/src/styles/`，图表/图谱颜色辅助位于对应 config/utils。组件优先消费已有变量，不重新声明局部主题。

## 规则

- 颜色、间距、圆角、阴影、z-index 和动画使用设计令牌。
- 卡片圆角保持克制；页面 section 不伪装成浮动卡片。
- 字体大小不随 viewport width 缩放；letter-spacing 不设负值。
- 固定格式控件使用稳定尺寸和响应式约束，动态内容不引发布局跳动。
- 颜色不能只依赖单色差异表达状态；保留文本/图标辅助。
- ECharts/G6 主题与应用 token 对齐。
- 动画尊重 reduced-motion，且不阻塞核心操作。

## 验证

检查桌面/移动、长中文、空数据、错误提示、hover/focus 和明暗背景对比；避免内容遮挡和横向溢出。
