# 通用组件规范

## 规则

- 组件拥有一个清晰视图职责，通过 typed props/emits 与外部通信。
- 通用组件不直接访问业务 Store，除非它本身是明确的领域容器。
- 图表组件接收数据/options 或受控交互回调，并在卸载时释放实例。
- 按钮、菜单、toggle、tab、slider 等使用符合语义的 Element Plus 控件和图标。
- 所有组件支持 loading/empty/error/disabled 等自然状态。
- 无障碍名称、键盘焦点和 tooltip 适用于图标按钮。
- 不在卡片内继续嵌套装饰性卡片，不使用文本 pill 替代熟悉图标。

## 测试

测试 props/emits、空状态、错误边界和关键交互。视觉组件变化还需浏览器截图检查桌面和移动视口。
