# 页面组件规范

## 边界

`frontend/src/pages/` 是路由级容器。当前页面清单以 `router/index.ts` 和磁盘为准，不在文档手写数量。

## 规则

- 页面组合 Store、composable 和组件，不直接复制 API transport。
- 页面必须提供 loading、empty、error、permission 和正常状态。
- 复杂流程拆分到领域组件与 composable，避免单文件持续增长。
- 表单提交前使用 `useFormValidation` 或等价 Schema 边界。
- 导航使用 route name/path 契约，不手写与 router 冲突的链接。
- 响应式布局必须保证文本和交互不重叠。

## 验证

Vitest 覆盖关键页面状态；Playwright 覆盖登录、导航、主要表单和跨页业务结果。浏览器报告归档，不放在 pages/tests 目录冒充当前结果。
