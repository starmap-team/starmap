# 前端构建与质量规范

## 配置事实源

- `package.json`：命令和依赖。
- `vite.config.ts`：dev server、proxy、chunk 策略。
- `tsconfig*.json`：TypeScript 编译范围。
- `.eslintrc.json`：lint 规则。
- `src/config/apiBase.ts`：API base path。

## 规则

- 使用 lockfile 安装；CI 与本地执行同一 npm scripts。
- API proxy 只转发 `/api` 到后端，不改写 `/api/v1` 语义。
- 生产构建不得注入第二个冲突 API base。
- 新依赖先确认现有库不能满足，并评估包体/维护风险。
- 生成的 OpenAPI 类型由命令更新，不手工编辑。
- ESLint warning 上限和 TypeScript 严格度以配置为准。

## 门禁

```bash
cd frontend
npm run gen:api
npm run lint
npm run typecheck
npm run test
npm run build
```
