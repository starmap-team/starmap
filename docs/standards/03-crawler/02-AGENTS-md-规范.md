# AGENTS.md 编写规范

## 目的

`AGENTS.md` 为进入目录的 agent 提供局部边界，不复制整个项目 README 或历史状态。

## 必要内容

- `OVERVIEW`：该目录唯一职责。
- `WHERE TO LOOK` 或简洁结构：按任务定位真实文件。
- `CONVENTIONS`：本目录特有强规则。
- `ANTI-PATTERNS`：高风险错误做法。
- 需要时提供可运行的验证命令。

## 规则

- 使用当前文件名，不维护会漂移的文件数、行数、测试通过数。
- 不记录 P0、Sprint、负责人或临时 WIP 状态；这些属于 tracker/归档。
- 子目录 AGENTS 只补充父规则，不冲突、不整段复制。
- 新文件移动后同步最近 AGENTS 的定位表。
- 命令必须从该目录上下文可执行或明确工作目录。
- 历史报告只链接 `docs/archive/`，不得当作当前验收结论。
