# 爬虫模块规范

## 当前边界

- 活跃本地来源以 `crawler/spiders/` 中现存文件和数据库数据源状态为准；已下线的 spider 必须从该目录移除，不保留禁用副本。
- Apify 等采集脚本位于 `crawler/scripts/`，按需使用且遵循同样的合规与审计规则。

## 规则

- robots、站点条款、频率限制和个人信息处理优先于采集成功率。
- 403/429 触发退避/熔断，保留审计记录。
- 清洗、去重、持久化分层，不在 spider 内直接写后端业务表。
- 数据源启停、keyword 和 limit 来自配置/数据库，不写死在流程。
- crawler schema 变化使用其本地 migration；与后端桥接使用明确契约。
- 凭据、Cookie、代理和真实响应样本不进入仓库。

## 验证

```bash
python -m compileall crawler -q
python -m pytest crawler/tests -v
```

真实站点测试必须显式运行，不作为普通 CI 默认任务。
