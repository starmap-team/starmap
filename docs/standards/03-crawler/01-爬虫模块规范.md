# 爬虫模块规范文档

## 1. 模块概述

**职责定位**：StarMap 系统的数据采集引擎，负责从多个招聘网站（拉勾、51Job、BOSS 直聘等）抓取职位描述（JD）数据，支持 Scrapy HTTP 和 Playwright-stealth 双模式抓取，并提供数据清洗、去重、持久化及合规审计功能。

**核心目标**：
- 支持多站点（拉勾/51Job/BOSS/猎聘/智联）的职位数据抓取
- 提供 Scrapy HTTP 和 Playwright-stealth 双模式抓取能力
- 实现数据清洗、去重、增量更新等 ETL 流程
- 确保抓取行为合规（robots.txt、QPS 限速、代理熔断、审计日志）
- 支持 Apify 云抓取作为备选方案

**在系统中的位置**：
- 上游：招聘网站（拉勾、51Job、BOSS 直聘等）
- 下游：`starmap-contracts/openapi.yaml`（数据格式契约）、`backend/`（后端服务）
- 依赖：PostgreSQL（持久化）、Neo4j（图谱存储）、Redis（缓存/队列）

## 5. 编码规范（本模块特有）

### 5.1 爬虫开发约定
- 所有 spider 必须继承 `scrapy.Spider` 或实现兼容接口
- 必须设置 `name`、`allowed_domains` 属性
- 请求前必须调用 `RateLimiter.wait()` 控制 QPS
- 抓取结果必须包含 `source_site`、`source_url`、`content_hash`

### 5.2 Stealth 模式约定
- 使用 `create_stealth_context()` 创建浏览器上下文
- 必须配置 `locale="zh-CN"`、`timezone_id="Asia/Shanghai"`
- 页面访问后必须等待内容渲染（`wait_for_selector`）
- 资源释放：必须关闭 page、browser、playwright

### 5.3 合规约定
- 抓取前必须检查 `robots.txt`（`is_allowed()`）
- QPS 必须 <= 1（`DEFAULT_SLEEP = 2.0`）
- 所有请求必须记录到 `compliance_log`
- 代理使用 `pick_proxy()` 轮询选择，失败时触发熔断

### 5.4 数据持久化约定
- 原始数据存入 `jd_raw` 表
- 清洗后数据存入 `clean_text` 字段
- 去重使用 SimHash 指纹（`content_hash` 字段）
- 状态流转：`raw` → `extracted` / `duplicate` / `failed`

### 5.5 反模式
- **禁止**在 spider 中硬编码敏感信息（如密码、API 密钥）
- **禁止**绕过 `robots.txt` 检查
- **禁止**不使用代理直接大量抓取（易被封禁）
- **禁止**在 spider 中直接操作数据库（应通过 pipeline）
- **禁止**忽略异常（必须记录日志并设置 `error_msg`）

## 7. 变更管理

### 修改检查清单

- [ ] 新增 spider 是否设置了 `name` 和 `allowed_domains`？
- [ ] 新增 spider 是否使用了 `RateLimiter`？
- [ ] 新增 spider 是否记录了 `compliance_log`？
- [ ] 新增 spider 是否生成了 `content_hash`？
- [ ] 修改代理逻辑是否同步更新了 `proxy_middleware.py`？
- [ ] 修改数据模型是否同步更新了 `models.py` 和迁移脚本？
- [ ] 新增站点是否在 `config.py` 的 `SOURCE_SITE_MAP` 中注册？
- [ ] 是否与 `starmap-contracts/openapi.yaml` 的数据格式一致？

### 契约影响
- 爬虫输出的数据格式必须与 `starmap-contracts/models/` 的 Pydantic 模型一致
- 新增字段需同步更新 `models.py` 和数据库迁移脚本
- API 变更可能影响 `pipeline_bridge.py` 的数据传递

### 迁移要求
- 新增站点：需配置 `SOURCE_SITE_MAP`、`KEYWORDS`、站点 URL 模板
- 代理变更：需更新 `PROXY_LIST` 环境变量和 `proxy_middleware.py`
- 数据库变更：需执行 Alembic 迁移
- Stealth 参数变更：需测试所有 stealth spider
