# 脚本工具规范

## 分类

脚本按契约/Schema、初始化、数据同步、评估、离线 fixture、运维和 deprecated 分类。当前清单以 `rg --files scripts` 为准。

## 规则

- 提供 `--help`、明确工作目录和所需环境变量。
- 写操作幂等；高风险操作提供 dry-run/确认和清晰日志。
- 不使用脚本绕过 API 审核、ORM 约束或 PG->Neo4j 投影边界。
- fixture/demo/offline 输出带明确来源，禁止进入生产数据。
- deprecated 脚本不被 CI、Compose 或运行入口调用。
- 报告默认写 ignored 结果目录；需要留证时移动到 docs/archive。
- 不在脚本或 README 保存真实 token、密码、Cookie、生产 URL。

## 文档

`scripts/README.md` 提供分类导航；每个复杂子目录可有局部 README/AGENTS，不维护易漂移的脚本数和行数。
