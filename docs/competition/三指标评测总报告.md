### 8-20 假失败根因（已确认）

F1=0.7569 并非模型能力问题：当时 LLM API key 失效（讯飞 Spark 全部 `AppIdNoAuthError` / HMAC 不匹配）且未配置 DashScope key，降级链落到**规则抽取**，拉低指标。重配有效 `DASHSCOPE_API_KEY` 后全量重跑，110+50 样本零 LLM connection error，指标恢复并超过历史水平。
