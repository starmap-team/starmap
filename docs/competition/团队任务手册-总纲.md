## 〇、全员第一步：理解项目是什么

**StarMap（星图）是什么？**
一个"人才能力星云"系统——从网上抓取招聘 JD（岗位描述），用 AI 抽取技能，构建"岗位-技能"知识图谱，帮你：
1. **发现新岗位**：哪些技能在爆发 → 哪些岗位在兴起（模块A，赛项核心）
2. **更新旧岗位**：岗位技能要求怎么变了（如 Java 工程师开始要 AI 技能）（模块B）
3. **看图**：全部岗位和技能的关系图谱，按技术栈/级别切换视图（模块C）
4. **人岗匹配**：上传简历 → 算你和目标岗位差距 → 给学习路径（模块D）

**比赛要什么**（科大讯飞 XH-202621）：
- 系统能跑通"采集→发现→更新→图谱→匹配"全流程（30 分）
- 三个准确率 ≥90%：JD 解析 / 简历提取 / 人岗匹配（30 分）
- 界面好用、图谱流畅（15 分）
- 技术创新：数据去重防幻觉、动态演化（25 分）

**当前状态**（2026-08-23 已实机验证）：
- 公网已部署，模块A（新岗位发现）和模块B（更新说明）刚上线
- 三指标证据已齐：JD 0.9622 / 简历 0.9158 / 匹配 97.45%
- 数据：503 岗位 / 702 技能 / 1153 关系

## 一、环境准备（所有成员必做，1 小时）

### 1. 装工具
- **Git**（版本管理）、**Docker Desktop**（跑项目）、**VS Code**（编辑器）
- 可选：Python 3.11-3.12、Node.js 20+、Postman（调 API 用）

### 2. 拉取项目（从 0 开始）
```bash
# 克隆仓库（需要 GitHub 账号，加入 starmap-team 组织）
git clone git@github.com:starmap-team/starmap.git
cd starmap

# 切到部署分支（当前含赛项模块A/B 的版本）
git checkout deploy/production

# 查看分支结构（理解代码组织）
git branch -a          # 看所有分支
git log --oneline -10  # 看最近提交
```

### 3. 本地跑起来（理解系统怎么运转）
```bash
# 准备环境变量
cp .env.example .env

# 启动全部服务（PostgreSQL/Neo4j/Redis/后端/前端）
docker compose -f docker-compose.dev.yml up -d

# 等 2-3 分钟，然后验证
curl http://localhost:8000/health    # 应返回 ok
```

启动后访问：
- 前端界面：http://localhost:5173
- API 文档（**最重要，看这个理解系统能力**）：http://localhost:8000/docs
- 图谱数据库 Neo4j：http://localhost:7474

### 4. 理解代码结构（花 30 分钟逛一遍）
```
starmap/
├── backend/               # Python 后端（FastAPI）
│   ├── app/api/v1/        # API 接口层（前端调的接口都在这）
│   ├── app/core/          # 核心业务逻辑
│   │   ├── evolution/     # 演化模块（新岗位发现/能力更新）★赛项重点
│   │   ├── extraction/    # JD/简历抽取（AI 解析）
│   │   ├── matching/      # 人岗匹配（评分）
│   │   └── pipeline/      # 数据流水线（采集→清洗→入库）
│   ├── app/services/      # 服务层（业务编排）
│   └── tests/             # 测试
├── crawler/               # 爬虫（抓取招聘 JD）
│   └── spiders/           # 各平台爬虫（v2ex/remoteok 等）
├── frontend/              # 前端（Vue3）
│   └── src/pages/         # 页面（Home 图谱/MatchDiagnosis 匹配等）
├── evaluation/            # 评测（三指标验证）
└── docs/                  # 文档
```

**推荐理解路径**（按顺序看）：
1. `http://localhost:8000/docs` 逛一遍所有 API（10 分钟）
2. `frontend/src/pages/` 看每个页面对应什么功能（10 分钟）
3. `backend/app/core/evolution/` 看演化模块（赛项核心，10 分钟）
